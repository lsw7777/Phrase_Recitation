# Phrase Studio · 短语学习室

> 把短语，变成你的表达。浏览、回忆、再练习。建立属于自己的短语库。

**Phrase Studio** 是一个纯前端、单文件（Single-File）的英语短语动词（Phrasal Verbs）学习与自测工具。无需后端服务器，无需安装任何依赖，打开 HTML 文件即可在浏览器中直接运行。

---

## ✨ 功能特性

### 📖 短语卡片模式 (Browse)
- **动词分类筛选**：左侧边栏按核心动词（run, hold, work, get, look 等 30 个分类）快速筛选短语。
- **动词快速定位**：侧边栏内置动词搜索框，输入动词名可实时过滤分类列表，按回车直接跳转到第一个匹配的动词。
- **实时搜索**：支持对英文短语、中文释义、英文例句进行模糊搜索。
- **收藏系统**：点击星号（☆/★）收藏重点短语，支持“只看收藏”过滤。
- **释义隐藏**：一键隐藏卡片上的中文释义，用于自我测试。
- **掌握状态追踪**：显示每个短语当前的掌握情况（未测试 / 需复习 / 已掌握）。

### 🧠 卡片测试模式 (Test)
- **主动回忆机制**：先看英文短语，大脑回忆中文意思后，再点击卡片翻转查看答案。
- **灵活的练习范围**：支持选择“当前筛选”、“全部”、“收藏”、“需复习”或“未测试”的短语作为题库。
- **随机/顺序出卡**：支持打乱顺序或按原始顺序进行测试。
- **自评打分**：每道题可标记为“↺ 需复习”或“✓ 已掌握”。
- **快捷键支持**：
  - 未翻开：`←` 上一张；`→` 显示答案
  - 已翻开：`←` 上一张；`Space` 需复习；`→` 已掌握
- **结果统计与重练**：一轮结束后展示正确率，并支持一键“再练需复习的短语”。

### 💾 本地数据持久化
- 利用浏览器的 `IndexedDB`(`或LocalStorage`) 自动保存**收藏列表**和**掌握进度**。
- 刷新页面或关闭浏览器后重新打开，学习记录不会丢失。
- 若浏览器处于隐私模式禁用了存储，会友好提示“仅在当前页面有效”。

## 🎨 UI 与设计

- **主题配色**：采用类似 Claude Code 风格的**暖橙色主题**（Orange Theme），视觉温和不刺眼。
- **排版设计**：Hero 区域标题使用了小众美观的字体组合（衬线小字 + 楷体标题 + 仿宋题注），提升阅读体验。
- **响应式布局**：完美适配桌面端（3列网格）、平板（2列网格）和手机端（单列/双列自适应）。
- **无障碍访问 (a11y)**：包含 `aria-label`、`aria-pressed`、`role="status"` 等属性，支持键盘导航和屏幕阅读器。

## 🚀 快速开始

### 方式一：直接双击打开
直接双击 `phrase_test.html` 文件，它会在你的默认浏览器中打开并开始使用。
